# 画面と地図のカスタマイズ

設定の「一般」に「起動時の表示」「機能メニューの編集」、
「地図・表示」に「地図の操作」「地図の情報量」を追加。
既存の設定ナビゲーション、配色、スイッチを使用する。

- 起動時の表示：初期タブを指定、または前回のタブを復元する。
  URL の `tab` を優先。地図は標準、日本以外も含めて手動保存した範囲、
  前回の範囲を選べる。保存対象は中心、ズーム、回転、傾き。
  保存範囲がある起動では位置情報ウォッチの初回自動移動で上書きしない。
- 機能メニュー：表示／非表示、お気に入りの先頭固定。
  設定ボタンは非表示にできない。既存の長押し並べ替えを共有する。
  権限による `hidden` と個人の表示設定は別に管理し、権限を変更しない。
- 地図の操作：通常の地震選択時の自動フォーカス、最大拡大率（6/7.4/9）、
  自動移動の速度（ゆっくり／標準／速い／なし）。拡大率の標準は各画面の従来値。
  震源・観測点は範囲内に維持。
  EEW のフォーカス可否は既存設定で独立管理。OS の動きを減らす設定を優先。
- 地図の情報量：AMeDAS 地点名、数値の表示、地点名と数値マーカーの大きさ、
  行政界の表示と濃さ。数値非表示ではズーム後も円を維持する。
  風向・風速表示、震度・警報の意味を持つ配色や情報は変更しない。

全項目は現在の挙動を標準値とし、各画面から標準に戻せる。
設定内の単一選択は配色と同じチェック付きリストへ統一する。
起動時の表示、操作、情報量、時計のボタン、配色凡例の観測項目・集計時間は
共通コンポーネントで既存のselectの値・changeイベントに接続する。
動的な選択肢と利用不可・非表示の状態を同期し、矢印キー・Home・Endに対応する。
既存の配色などのチェック付きリスト、トグル、調整スライダーは維持する。
「一般 → 外観」の「背景の透け具合」は標準・半透明・不透明を選択できる。
要約、下部ナビゲーション、時計、地図上の操作ボタン、メニュー、モーダルに
同時反映する。背景の選択は配色と同じチェック付きリストとし、矢印キーでも選べる。
半透明のときは濃さ40〜100%、ぼかし0〜24pxのスライダーを表示する。
標準では外側の面だけに12pxの背景ぼかしと控えめな彩度補正を
適用し、背景の不透明度はダーク78%・ライト82%、不透明は100%とする。
濃さを調整した後は両テーマに指定した値を適用する。ぼかし0は背景フィルターを無効にする。
操作中はCSSだけでプレビューし、変更の確定時に端末へ保存する。地図データの再処理はしない。
文字やデータの配色・濃さは変えず、内部のボタンやカードにぼかしを重ねない。
背景ぼかし非対応のブラウザーでは88%の背景にフォールバックする。テーマに合わせて明暗を切り替え、
保存した設定を初回描画前にも適用する。標準では既存のスタイルを維持する。
メニューのリセット対象は表示・お気に入りで、既存の長押し並び順は維持する。
保存先は `meteoscope.customization.v1`。前回のタブ・地図は
`meteoscope.lastTab.v1` / `meteoscope.lastView.v1` に保存する。
地図範囲の永続化は保存操作、または「前回」を選んだ場合だけ行い、
サーバー同期や新規通信は追加しない。保存できない環境ではセッション内で反映する。

検証は `Tests/CustomizationTests.mjs`、既存のメニュー並べ替え・AMeDAS
マーカー・地形・タブ遷移テストを利用する。iOS ネイティブのプロジェクトは
このチェックアウトに存在せず、Web/PWA の共通コードとして反映する。
