# 深発近似の観測比較

この比較は学習用モデルの偏りを把握するためのものです。実際の深発地震の震度分布、波形、EEWを再現・予測できることを保証しません。表示する注意書きは維持します。

## データと指標

気象庁の[震度データベース](https://www.data.jma.go.jp/eqdb/data/shindo/)から、深さ156〜682kmの14地震・9,556地点の発表記録を収集しました。[CMTカタログ](https://www.data.jma.go.jp/eqev/data/mech/cmt/)でMwを確認した11地震・8,258地点を数値比較に使い、未確認の3地震・1,298地点は別配列に保存し、Mwに基づく平均誤差へ混ぜません。震源位置・深さは震度データベースの震源要素です。気象庁マグニチュードMとMwは混同しません。取得日は2026年11月15日です。各事例の出典URL、Mw、深さ、観測点座標・震度階級は `Tests/fixtures/simulation-deep-observations.json` に保存しています。観測された地点だけを対象とし、記録のない地点を震度0とは扱いません。

計測震度の実数値は取得していないため、各階級の区間（例：震度3は2.5以上3.5未満）から推定値が外れた分を誤差とします。区間内なら0、区間外なら近い端からの距離です。実数の計測震度との通常のMAEや的中率とは異なります。観測点数が多い事例だけに評価が偏らないよう、各事例の平均誤差を等しい重みで平均します。

地盤補正なし、同じ地点・震源・Mwを使い、公開済み `861a97f` を基準としています。外部の地盤モデルに依存せずCIでも再計算できます。過去の地盤条件や観測点移設の再現は含みません。

## 規模補正と結果

深発近似のlog10(PGV)に、`clamp(0.35 × (min(Mw, 8.3) − 7.5), −0.65, 0.25)` の補正を追加します。Mw5以下ではこの規模補正を加えず、Mw5〜5.5で連続的に適用します。既存の150〜200kmの移行重みも掛け、150km以下の式・実際の震源距離・P/S到達時刻は変更しません。海溝から離れた側の負のV1補正は、従来の50km幅の移行では156〜175kmで過小になっていたため、150〜155kmで連続的に適用します。正の増幅・V2・規模補正は従来の移行幅を保ちます。これらは複数の観測分布で見られた偏りを調整するMeteoScope独自の有界な補正・移行条件で、公表GMPEの項ではありません。個別地点の実測値への置換、地域名による強制的な震度0、乱数によるばらつきは加えません。

## 近畿・東海の分布の確認

深さ172kmの利用者画像は正確な座標が未確認のため、同一震源の実観測とは比較していません。近い深さの2007年・2014年、および東海道南方沖の2024年を追加し、発表地域と模擬表示を調べました。地域は同じ予報区ポリゴンで照合しています。2007年のMwは未確認のため、この地域パターン確認だけはM5.8を代理入力に使い、前記のMw平均誤差には含めません。

| 事例 | 近畿の発表地点 / 模擬表示地点 | 東海の発表地点 / 模擬表示地点 |
| --- | ---: | ---: |
| 2007/01/16 静岡県伊豆地方・深さ175km | 0 / 0 | 51 / 170 |
| 2014/05/05 伊豆大島近海・深さ156km | 6 / 0 | 127 / 262 |
| 2024/05/30 東海道南方沖・深さ405km | 0 / 0 | 0 / 0 |

近畿への広い過大表示を抑えられる一方、東海の弱い揺れの広がりや、2014年の近畿6地点の観測を再現できていません。地域全体が常に揺れないとは扱いません。発表当時と現在の観測点配置・運用状況は異なるため、地点数を1対1の的中率には換算しません。「発表なし」を各観測点の確定的な震度0とも扱いません。気象庁の地動最大値CSVも確認しましたが、取得した2015年のCSVに確定的な震度0の記録はなく、未発表を負例として捏造しません。

`node scripts/validate-simulation-deep-intensity.mjs` で全事例を再計算できます。テストでは平均の改善と事例ごとの悪化上限を確認し、不利な事例も比較対象に残します。
