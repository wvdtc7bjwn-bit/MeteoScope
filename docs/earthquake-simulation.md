# 地震シミュレーション

地震タブの「最近の地震」で、凡例の直下にある波形アイコンから任意の緯度・経度・モーメントマグニチュードMw・深さを設定できます。地図上での震源選択にも対応します。南海トラフ・千島海溝・日本海溝は、震源域と規模・深さの代表設定を読み込み、規模・深さ・破壊開始位置・破壊速度を変更できます。南海トラフは全割れ・半割れ東側・半割れ西側を選択できます。

再生・一時停止・0.5/1/2/5倍速・時刻移動・再生し直し・終了に対応します。観測点の位置は既存の気象庁観測点カタログを使用しますが、表示する揺れ・震度は計算値です。P波到達前は小さい灰色の点、到達後は模擬震度に応じた色で表示します。点の周囲の発光・脈動や自動ズーム・自動タブ移動は行いません。地図移動は「震源を表示」の操作時だけです。各点をタップすると地点名と概算のP/S到達時間を表示します。

再生パネルは小さい2段表示で、一時停止・時刻・終了を常時表示します。速度・震源表示・設定と地盤補正の適用地点数は「操作」から開きます。任意震源の地名は既存の震央地名ポリゴンに照合し、範囲外・取得失敗では地名不明とします。観測点の丸と数字は通常の地震表示と同じ一体の画像を使用します。

## 移植元と変更内容

- 移植元: [itachi-kun-itc/WE-Simulator](https://github.com/itachi-kun-itc/WE-Simulator)。利用者から移植許可取得済みとの明示を受けて導入。
- 参照リビジョン: `3b0f37d830b1994bac9a69c9686a90bcc24477c1`、`web/app.js`。
- 移植対象: P/S波に対する地点応答・震度の立ち上がりモデル、模擬報の時間配分、3つの想定震源域の経路と外形・南海トラフ半割れケース。最大震度を出す旧減衰式は過大評価対策として置き換え、重複して残していません。
- `src/simulation/weSimulatorModel.js` は移植元の数式をUIから分離したものです。P/S波に対する地点応答、震度の立ち上がり、模擬報の時間配分を利用しています。配色はMeteoScopeの既存の震度配色に合わせています。古い震度階級の再現・音声・投稿・アカウント・移植元のEEW画面は取り込みません。
- 想定モデルは移植元の震源域近似です。厳密な公的強震動計算や、将来起きる地震の予測ではありません。千島海溝・日本海溝の初期Mは移植元の津波断層モデル由来の代表設定で、公式な強震動分布を再現する保証はありません。
- 移植元の有限震源サンプリングと破壊遅延を利用します。P/S波の伝播と観測点の到達時間は、MeteoScopeの既存JMA2001走時表を共用し、同じ深さの表を順引き・逆引きします。未破壊の小震源からは波を出しません。
- 地盤補正なしではS波速度400m/s相当の参考計算、補正ありでは1kmメッシュの表層地盤速度増幅率を反映します。建物・津波・被害・地盤の非線形性は計算しません。地図上の破壊点は破壊開始後に色を変えます。

### 最大震度の参考計算

移植元の簡易減衰式は、南海トラフMw9などで広い範囲に震度7を出すため、そのまま最大震度の計算には使用しません。`src/simulation/intensityModel.js` で、[J-SHISの司・翠川(1999)式と計測震度への換算](https://www.j-map.bosai.go.jp/j-map/result/tn_246/html/html/2-4-1.html)に基づく基盤上の参考値を計算します。PGV600を1.31倍してS波速度400m/s相当へ換算し、`I = 2.68 + 1.72 log10(PGV400)` を使用します。巨大地震のMwは[旧来の簡便法のMw8.3上限](https://www.j-shis.bosai.go.jp/j-map/result/tn_257/html/html/2-4-1.html)を適用します。

補正ありでは、このPGV400に地盤増幅率ARVを一度だけ乗じて計測震度へ換算します。つまり震度換算前の速度にARVを掛け、震度に単純にARVを掛ける処理はしません。地盤補正なし・欠測時のARVは1です。AVSは移植した立ち上がり応答の参考にも使用しますが、追加の増幅を重ねません。

地盤データは移植元がJ-SHIS V4の250mメッシュを1kmごとに平均した加工モデルで、個々の観測点直下の実測地盤ではありません。深部構造や地盤非線形応答の補正は含めていません。断層最短距離も簡略化した震源列からの近似です。小規模・深発・遠方などの条件では経験式の適用範囲外の外挿を含みます。補正後も学習用の参考値で、公式の2025年南海トラフ想定等の再現や避難判断には使用しません。

## 実情報との分離

模擬EEWはMeteoScopeの既存EEWカードに「シミュレーション」「実際の地震ではありません」を付けて表示します。陸上に加え、移植元の公開カタログに含まれるS-net・DONET・N-netの観測点位置を初報の検知計算に利用します。最初の有感相当検知点へのP波到達前は検知待ち、到達後は解析中として0.6秒の模擬処理待ちを置きます（最短の初報時刻は開始0.8秒）。海底の点を陸上の震度観測点として描いたり、地表震度として加算したりはしません。海底カタログ未取得時は陸上のみへ戻し、「操作」内に明示します。実際の波形解析・観測点の稼働状況・通信処理を再現する機能ではありません。

初報までは震度・震源地名・M・深さを「—」で表示します。模擬報ごとにM・深さ・予想最大震度を更新し、最終報で設定したM・深さと、その条件から求めた参考最大震度へ収束します。初報のMは過小推定、深さは粗い推定とする固定シナリオで、乱数による揺らぎは加えません。有限震源の最終報は破壊終了後とし、未破壊の間に最終値と確定しません。値は報の間で固定し、巻き戻し・再生で同じ値へ戻ります。観測点の揺れと波の伝播は元の設定条件を保ち、模擬EEWの深さ修正に引きずられません。実際のEEW受信状態には書き込まず、実発表の通知や発表中表示も発生させません。

途中の報を断層破壊終了まで引き延ばさず、最大3秒間隔で更新します。初期のM・深さは早めに収束させ、長い破壊が続く場合は3秒ごとの確認報を追加して、地域の予測も更新します。その報までに既に検知した模擬震度を予想値の下限に含め、観測点に6弱が出ているのに予想最大が4のまま残る不整合を防ぎます。これは教材用の更新シナリオで、個々の実EEWの報数・間隔を忠実に再現するものではありません。

警報対象地域は赤く塗ります。実EEWでは配信された地域別の警報指定を優先し、指定がない場合だけ警報状態と予想震度4以上を条件にします。シミュレーションでは各観測点を既存の予報区ポリゴンに照合し、報ごとの地域内最大参考震度を計算します。全体の最大が5弱以上となる報で、地域内最大が4以上の地域を模擬警報対象とします。[気象庁の警報基準](https://www.jma.go.jp/jma/kishou/know/faq/faq25.html)を参考にしていますが、長周期地震動・実際の解析・観測点がない範囲の面的な最大値を再現するものではありません。赤い地域は報の更新・巻き戻し・終了で更新・解除し、凡例と地域詳細に用途を表示します。

有限震源の模擬EEWは、その報の時刻までに破壊が始まった小震源からの距離を使います。まだ破壊していない遠方の小震源を、初報から地域予測へ加えることはしません。

実EEWを受信すると、準備中の取得・計算も含めて中断し、模擬観測点・震源域・波を消して実情報を表示します。タブ切り替え・火山表示への切り替え・震央分布や履歴の選択・ローカルEEWテストでも終了します。終了後は通常の地震情報を表示します。画面の非表示時は再生を一時停止し、準備中であれば取得を中断します。

## 読み込みと保存

計算モデル・走時表は設定を開いた時、観測点カタログと任意震源の地名ポリゴンは開始時に読み込みます。補正ありの初回のみ[固定リビジョンの加工済み地盤モデル](https://raw.githubusercontent.com/itachi-kun-itc/WE-Simulator/3b0f37d830b1994bac9a69c9686a90bcc24477c1/web/data/ground_model.json)（展開後約16MB）をブラウザーが直接取得し、成功後はメモリーとHTTPキャッシュを利用します。原データを本リポジトリへ同梱・再配布しません。全地点へ同じ係数を当てず、対応する1kmメッシュのARVがない場合はその地点だけ補正なしとし、適用地点数・地点詳細で明示します。

通常の初期地図表示に追加取得を発生させません。準備は分割してUIに処理を戻します。通常は15秒、地盤取得を伴う場合は45秒でタイムアウトし、失敗を補正済みとして扱わず再試行できます。設定の閉じる操作・実EEW・タブ切り替えで準備中の通信を中断します。

再生は一つのフレームループで行い、通常は最大10回/秒、動きを減らす設定では最大4回/秒で地図を更新します。模擬時刻は実際のEEWの時計と分離し、一時停止・速度変更・逆方向の時刻移動でも到達表示が一致します。設定と計算結果はメモリー内だけで保持し、サーバー・D1・AI APIへ送信しません。

EEW要約の更新は検知・解析・報数の変化時だけとし、同じ報の間は作り直しません。取得した全国地盤モデルは、観測点に必要なメッシュだけをメモリーに保持し、全国分を再生中ずっと保持することを避けています。
