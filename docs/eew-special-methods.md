# 特殊EEWの解釈（2026-11-16）

## 配信仕様と制約

- Wolfx: https://wolfx.jp/docs/open-api/
- 気象庁: https://www.jma.go.jp/jma/kishou/know/jishin/eew/shikumi/shikumi.html
- PLUM: https://www.data.jma.go.jp/eew/data/nc/plum/
- 精度コード参考: https://dmdata.jp/docs/reference/conversion/json/schema/eew-information/
- 参考実装: https://github.com/YumNumm/EQMonitor/blob/main/app/lib/feature/eew/data/eew_alive_telegram.dart

WolfxのAccuracyは説明文字列であり、生コードの対応を保証する資料ではない。数字だけからIPFや観測点数を推定しない。WarnArea.Typeは予報／警報、Timeは警報発表時刻。地域別PLUM・到達予想時刻は取得できないためunknown/nullを保存する。

2026-11-16に公式仕様とHTTP/WebSocketの実レスポンスを再確認した。`Magnitude`を優先し、廃止予定の旧綴り`Magunitude`だけが届く場合も受理する。新フィールドのみでもMが表示できることをテストする。`WarnArea.Shindo1`は最大、`Shindo2`は最小であり、内部の`from`／`to`を下限／上限にそろえる。逆順のペアも階級順に並べ、片方が欠損した場合は不明な値を補わない。

`CodeType`が「最大予測震度のみの緊急地震速報」と完全一致する場合、レベル法の発表として扱う。`Accuracy`が欠損、または通常のIPFに見える値でも、この発表区分では震源を確定しない。従来のP波／S波レベル越えの精度説明も維持する。`CodeType`は震源推定方式を網羅したフィールドではないため、その他の文字列からIPF／PLUMを推測しない。

レベル法の`OriginTime`は互換性のため検知時刻の場合があり、深さ10kmも仮定値である。M・深さは「調査中」、位置は黄色の点線丸と「震源調査中」で表示し、P/S波描画と自動震源移動を抑制する。正式な仮定震源要素のフラグ`isAssumption`を立てる変更ではなく、`false`でもこの条件を適用する。同じEventIDの続報で通常の精度条件を満たせば通常表示へ戻る。未知値の互換値0だけから有効な震源と判断せず、通常報の正当な深さ0kmは引き続き扱う。

接続先はJMA専用の`wss://ws-api.wolfx.jp/jma_eew`を維持し、アプリ内の複数表示で共有する。JSON `heartbeat`への返信は仕様の手動コマンド`ping`とし、JSON `pong`へ返信を繰り返さない。従来の文字列`ping`への応答、再接続とHTTP補完は維持する。実接続ではJSON heartbeatとJMA速報を確認した。実際のレベル法発表の受信は未確認であり、仕様準拠のデータで正規化・画面テンプレート・描画式・続報遷移を検証する。

EQMonitorの現行mainでは依頼された旧モデルパスが存在せずeqapi_typesを使用している。有効速報の保持と低精度情報の描画除外を分離している点を参考にした。配信元の異なるisPlumなどをWolfxのフィールドとして移植していない。

## 判定

|情報|採用する根拠|波面|
|---|---|---|
|1点検知|原文の観測点数、または完全一致のIPF法(1点)説明|非表示|
|レベル法|CodeTypeの最大予測震度のみの発表、または精度説明のP波/S波レベル越え等の完全一致|非表示|
|IPF複数点|精度説明のIPF法(2〜4点)完全一致|震央と深さの両精度が利用可能な場合|
|PLUM|対象速報を明示する限定文型|単独では非表示|
|仮定震源|isAssumption|非表示|
|混合|通常方式/IPF法とPLUM法を併用との明示|通常震源の精度条件を満たす場合|
|判定不能|資料にない記述・欠損・コードのみ|非表示|

一般的なPLUM解説を検出する全文部分一致や未定義isPlumフラグは使用しない。原文の文型対応は限定的であり、全電文を解析する実装ではない。情報不足時は正常な速報自体を破棄しない。

## 表示とテスト

1点検知は黄色の点線丸と「1点検知・初期推定」、PLUM単独・仮定震源は黄色の点線丸と「仮定位置」、通常の震源推定は赤い×印で区別する。位置の説明は地図とEEW要約に表示し、日本語・英語に対応する。座標がない場合はマーカーも位置説明も地図へ出さない。

1点検知を仮定震源として扱う変更ではないため、受信したM・深さの数値は維持する。isAssumptionが指定された仮定のM・深さは従来どおり数値を表示しない。1点検知ではP/S波を出さず、続報で通常の精度条件を満たすと赤い×印へ更新し、初期推定のラベルを解除する。取消時はマーカーとラベルを共に消す。低精度の注意文、最終報・EventID別管理・通信方式は維持する。新しい点滅・画面移動は追加しない。

localhostには欠損ケース、レベル法、IPF複数点、混合と5秒後の方式遷移を追加。テスト表示は実配信ストアを更新しない。停止・別シナリオ選択時に遷移タイマーを解放する。

実際のWolfx配信原文全種類とiPhone実機での検証は未実施。実配信の説明文字列に未対応の表記がある場合は波面を抑制する。この制限は受信・区域予測震度の表示を停止しない。新規サーバー・通信・課金リソースは追加しない。
