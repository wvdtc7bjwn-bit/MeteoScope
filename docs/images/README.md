# READMEの画面画像

2026年11月14日、MeteoScopeのローカル開発環境で実画面を撮影しました。
掲載内容を作り替えたり、観測値や発表文を合成したりした画像ではありません。

| ファイル | 表示サイズ | 内容 |
| --- | --- | --- |
| `radar-desktop.jpg` | 1440 × 900 | ライトモードの全国雨雲レーダー |
| `earthquake-mobile.jpg` | 393 × 851 | 最近の地震と細分区域最大震度 |
| `weekly-mobile.jpg` | 393 × 851 | 東京地方の週間天気予報 |

画像内の気象・地震情報は撮影時点の資料で、現在の状況を示しません。
開発環境では先行機能が有効なため、公開版で許可済みアカウントに限り表示される
チャットボタンや「過去の地震」も含まれます。位置情報はオフの状態で撮影し、
アカウント情報・投稿内容・個人の位置を掲載していません。

気象・地震・週間予報の出典は気象庁です。地図などの取得元・加工内容は
[データ出典一覧](../../DATA_SOURCES.md)を参照してください。
