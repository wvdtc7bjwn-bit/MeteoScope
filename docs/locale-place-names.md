# 英語の地名表示

- `src/ui/placeNamesEn.generated.js` は、既存の震央区域データの
  `name` / `name_en`、旧震央地名の英語表、国土地理院の日本地名集から生成します。
  形状は含めず、地名の表示のために区域GeoJSONを追加取得しません。
- 震央地名は名称全体で照合し、観測点名や「東」「地方」などの部分置換に
  分解しません。既存の個別翻訳がある場合はその表記を維持します。
- 市区町村の読みは初期バンドルに収録します。詳細な地名集とAMeDASの追加取得は
  独立して反映し、それぞれ10秒で中止します。通信失敗で既存の地名を消しません。
- `placeNameAliases.js` の字体照合は日本語表示を変更しません。
  補足した市町村の読みには同ファイルに参照先を記載しています。
- 観測点の小字などの読みが確認できない場合は、従来どおり市町村名と
  `station` を使う場合があります。全観測点の小字までの英訳を保証するものではありません。

データ更新後は次のコマンドで再生成します。既存の震央区域更新スクリプトと
日本地名集生成スクリプト（標準出力先）からも同じ生成処理を呼び出します。

```powershell
node scripts/build-place-name-translations.mjs
node Tests/LocalePlaceNameTests.mjs
```

生成結果と元データの一致、332震央区域、収録市区町村、4,368観測点の日本語残存、
字体違い、取得順序、タイムアウトを検査します。ブラウザー検証では実際の地震カード
描画処理と翻訳Observerを使用し、393×852と1440×1000で表示と言語切り替えを確認しました。
