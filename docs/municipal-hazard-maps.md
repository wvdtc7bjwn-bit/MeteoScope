# 自治体ハザードマップの選択

「防災マップ」の初期画面で都道府県・市区町村・災害の種類を選び、国土地理院の「わがまちハザードマップ」に掲載された自治体のページを別タブで開く。既存の端末内PDF・画像表示は別の表示項目として保持する。

## 出典・更新

- 公式配布ページ: https://disaportaldata.gsi.go.jp/hazardmap/copyright/opendata.html#wagamachi
- 利用条件: https://disaportal.gsi.go.jp/hazardmap/copyright/copyright.html
- `npm run data:update:hazard-maps` で15種類のCSVを順次取得し、Shift_JISから変換する。市町村コードは先頭ゼロを含む5桁の文字列。公開一覧の更新日は自治体の資料自体の改訂日ではない。
- `node scripts/update-municipal-hazard-maps.mjs --cached` で取得済みCSVから再生成できる。全ソースの検証成功後に内容ハッシュ付きの都道府県ファイルを生成し、最後に索引を差し替える。前のバージョンのファイルは既存キャッシュとの整合性のため自動削除しない。
- 初期データ取得日: 2026-11-14。47都道府県・1,720市区町村（掲載資料がある自治体のみ）。自治体間の重複コードを結合し、同じURLに複数の災害種別がある場合はまとめる。
- CSVのリンク先を利用し、自治体PDF・サイトの複製・再配信は行わない。個別資料の権利は作成機関に帰属する。自動更新や自治体全サイトへの巡回・リンクチェックは追加しない。

## 表示・制限

- 索引と選択した都道府県のみを必要時に読み込む。すべて静的ファイルで、追加のWorkers・D1・Durable Objects・APIキーは不要。
- 資料は通常の `target="_blank" rel="noopener noreferrer"` リンクで直接開く。非同期のwindow.openや自動タブ移動を使わず、自治体の埋め込み制限にも依存しない。
- 表示先のホスト名と外部リンク記号を示す。URLはhttp/httpsのみ許可し、認証情報やプライベートネットワークのアドレスは登録しない。外部のHTMLをアプリのHTMLとして解釈しない。
- 公式一覧は自治体サイトの入口の場合もある。自治体ページ内で対象の図面を選ぶ必要がある。全リンクが常時最新であることは保証しない。
- 地図未掲載を「リスクなし」「安全」と表現しない。出典を示す。一覧の更新日は公式配布ページと同梱の索引に保持する。
