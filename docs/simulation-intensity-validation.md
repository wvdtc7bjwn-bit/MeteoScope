# シミュレーション震度分布の比較検証（2026-11-16）

浅い任意震源を点からの距離だけで評価すると、断層近傍の強い揺れを小さく見積もりがちでした。Mから求める有限震源球の距離補正を共通処理へ追加し、弱い揺れ側の残差を限定的に補正しました。地点名・地震IDごとの調整や、震度7を強制する処理はありません。既知の活断層は球ではなく矩形面までの距離を使用します。

この比較は学習用モデルの回顧的なケース検証です。実際の震度分布・将来の地震を再現する保証や、防災判断用の精度評価ではありません。

## 比較方法

- [気象庁の震度データ](https://www.data.jma.go.jp/eqev/data/bulletin/shindo.html)と観測点履歴から、9地震・16,132地点の計測震度を収集しました。出典・除外点・震源・Mwは [テストデータ](../Tests/fixtures/simulation-shallow-observations.json) に記録しています。
- マグニチュードはMwです。MjをそのままMwへ置換しません。2004年中越のMw6.6は[東京大学地震研究所の整理](https://taro.eri.u-tokyo.ac.jp/saigai/chuetsu/chuetsu.html)、2007年中越沖のMw6.6は[気象庁月報](https://www.jma.go.jp/jma/press/0708/07a/0707jishin.pdf)、その他は震度資料の第2マグニチュードW等を参照しました。
- 変更前は既存の司・翠川式へ震源距離を入力、変更後は同じ式へ有限震源距離と限定的な残差補正を適用します。観測点と震源を同じにして比較します。波の到達時刻・深発近似はこの比較の対象外です。
- 地盤補正ありは既存のJ-SHIS由来1km加工ARVを両者に同じように適用します。地盤データは別途取得する既存モデルであり、この検証資料に生データは同梱しません。
- MAEは計測震度の絶対誤差平均です。「強震地点」は**実測**4.5以上（5弱以上）で選びます。総合値は観測点数の多い地震だけに偏らないよう、地震ごとのMAEを等重みで平均しています。
- 調整時の比較用4地震（熊本本震・前震、胆振、福島）とは別に5地震を確認しています。ただし全ケースを診断時に参照しており、未知データに対する独立・盲検評価ではありません。

## 式と制約

[気象庁の技術参考資料](https://www.jma.go.jp/jma/kishou/know/jishin/eew/katsuyou/reference.pdf)にある `log10 L = 0.5 Mw - 1.85` の球半径 `L/2` を参考に、浅い任意震源では `R = max(3, 震源距離 - 半径)` を使います。未知の巨大断層が一様な近距離になるのを避けるため、半径のMwは8.3で制限します。この半径上限はMeteoScopeの保守的な学習用仮定であり、気象庁の式そのものではありません。

球・矩形面の距離補正は100〜150kmで連続的に弱め、150km以上の既存深発モデルへ持ち込みません。浅い地震の弱震側に `0.3 × clamp((4.5 - I)/2, 0, 1)` を減算し、同じ深さ帯で補正を弱めます。0.3は今回のケース比較で確認した学習用残差係数で、原論文の係数ではありません。強震側に任意の増幅やランダム値は加えていません。

元の速度減衰式・Vs400への換算・地盤ARVは維持します。気象庁のVs700基準の換算係数を、Vs400用ARVへ混在させません。式の詳細は[実装説明](earthquake-simulation.md)を参照してください。

## 公的想定を優先する場合

読み込んだ公的な地表想定値は共通近似より優先し、ARVを二重に適用しません。欠測だけ近似計算し、適用地点数・出典・公表ケースを表示します。

南海トラフの**全割れ・東側半割れ・西側半割れは別ケース**です。基本・東側・西側・陸側・経験式・最大重ね合わせもデータに明示します。半割れで受け付けるのは基本・陸側です。異なる破壊ケース、規模、深さ、破壊開始位置には適用せず、全割れの分布の切り取りやMによる拡大縮小はしません。千島海溝・日本海溝も別モデルとして照合し、互いに転用しません。

今回、内閣府2025年南海トラフの数値データは未取得です。登録・ログインを必要とする配布データは同梱せず、読み込み機能だけを用意しています。公開版の初期状態は引き続き近似計算です。テストで使用した想定値は合成データであり、公的想定の再現検証とは区別します。

```sh
node scripts/validate-simulation-shallow-intensity.mjs

node Tests/SimulationShallowObservationTests.mjs
node Tests/SimulationSourceDistanceTests.mjs

```

観測点履歴の座標は分単位で、現在のカタログや直下の地盤メッシュとずれる場合があります。短時間の連続地震をまとめた震度Bグループも含みます。報告された観測点だけを比較し、報告のない地点を震度0と見なしません。固定された9地震による回帰検証であり、あらゆる地域・規模・深さで誤差が減ることを保証するテストではありません。
