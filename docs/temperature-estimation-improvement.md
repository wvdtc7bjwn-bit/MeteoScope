# 現在地の推定気温：全国検証を受けた改善

2026-11-26。アーリーアクセス限定・初期OFFを維持する。個別地点の地名・他社アプリの比較値を使った補正は行わない。

## 変更

標高補正後の気温を平均する際に、対象地点と標高の近い観測点の寄与を大きくした。距離・周辺環境の類似度に加え、次の係数を使用する。

`heightSimilarity = 1 / (1 + ((stationElevation - targetElevation) / 200m)^2)`

最終的なIDWの重みは `environmentSimilarity × heightSimilarity / distance^2`。観測点の選択順位にも同じ類似度を用いる。200mは前半の検証で選択した経験的な尺度であり、精度を保証する境界や物理定数ではない。

固定の気温減率0.0065℃/m、50km・最大8地点・最低3地点、品質・鮮度、水域判定、標高外挿の抑制は維持した。標高が使えない場合と通常のIDW比較では標高差の重みを使わない。動的減率は引き続き無効。

補間を断念して実測へ切り替えたとき、要約にも「実測」を付け、詳細の上部に「現在地の推定気温は表示できません。近隣観測点の実測値です。」と表示する。参照観測点の標高も併記した。読み込み中には「推定不可」を先に表示しない。数値を隠すことで誤差の改善に見せる処理は行っていない。

## 選択と検証

対象地点自身を必ず除外する観測点別LOOを使用。以前の全国検証と同じ公表標高・実装済みの水域スクリーン・環境データを共有する。

- 前半4時刻で尺度200/400/800mと、方位をそろえるための遠距離優先を抑える候補を比較し、1つに固定した。
- 後半5時刻は固定候補の採用／不採用だけを判断した。MAE・RMSE、同じ地点での推定誤差、推定件数、95%点、最大誤差、標高帯別の悪化を確認した。
- その後に新しく取得した18:20の観測を追加確認に使った。この時刻は候補選択に使っていないが、直前時刻と相関が強く、独立した季節別評価ではない。
- 方位優先の変更は採用しなかった。実装の設定値 `directionalReachRatio: 0` は既存動作の維持を意味する。

集計は `docs/data/temperature-improvement-validation.json` と `docs/data/temperature-improvement-fresh-validation.json`。全観測点の個別記録と元データは配信対象外の `.cache/temperature-audit/` に保持し、個人の現在地や他社アプリとの比較記録を含めない。

## 負荷と確認

追加のAPI、位置情報送信、D1、Durable Objects、定期処理はない。既存の候補地点・標高・環境データに対する軽い係数計算だけを加えた。設定OFFやアーリーアクセス無効時の取得・計算抑制は維持する。

検証処理は `prepareTemperatureAuditFrame` を共有し、候補比較のたびに幾何判定や全国データの取得を繰り返さない。補間・距離・品質判定・環境復号もアプリと同じ関数を利用する。通常IDW、標高欠測、実測への切替、読み込み中の表示の自動検査を追加した。

全182テストスイート成功・失敗0。関連26ケース成功。ビルド成功（261モジュール、既存の大きなチャンク警告あり）。スマホ幅430×932のダーク表示と320×568のライト表示で、推定方法・実測切替・観測点標高・スクロール・横あふれがないことを確認した。ライト配色の注意文は濃い色に調整して視認性を確保した。確認用ページは削除済み。実iPhoneの測定ではない。

端末に必要な参照点をあらかじめ用意したNode上の計算300回では、改善後の平均約0.27ms・95%点約0.61ms。これはデスクトップでの補間部分だけであり、全国点の絞り込み・地形判定・通信・描画は含まない。

全国1,286地点の改善前後CSVはローカルの `.cache/temperature-audit/improvement-stations.csv` に保存した。元の全国検証結果は比較基準として保持する。地形・土地利用だけを比較する過去の検証スクリプトには、標高差の重みを無効化する設定を明示して、比較条件が後の既定値で変わらないようにした。

iOS向けPWAも同じWebコードを利用し、リポジトリにはネイティブiOS/Xcodeプロジェクトはない。GitHub反映・CI・コミット・デプロイは指示を受けてから実施する。

次の精度改善には、別季節・別気象条件の検証、夜間逆転・盆地・沿岸の評価、気象庁の面的な実況解析との比較が必要。今回の公表標高による検証にはGPS・DEMの誤差を含まない。
