# 地図タイル版の試作

現行方式のローカル保存は`71dd081`、試作ブランチは`codex/static-map-tiles`です。
タイル版を本番ビルドで有効にする設定は`.env.production`に記録しています。

## 比較と戻し方

通常の`npm run dev`は従来のGeoJSON、本番用の`npm run build`はタイル版を使います。
ビルド環境変数`VITE_MAP_GEOMETRY`で方式を選べます（`vector` / `geojson`）。
元の方式へ戻す場合は、`VITE_MAP_GEOMETRY=geojson`を指定して再ビルド・再公開します。
元のGeoJSON、区域検索、地震・EEWの区域データは残しています。

PowerShellでのタイル版の例:

```powershell
$env:VITE_MAP_GEOMETRY='vector'
npm.cmd run build
Remove-Item Env:VITE_MAP_GEOMETRY
npm.cmd run preview -- --host 127.0.0.1
```

元の方式へ戻す例:

```powershell
$env:VITE_MAP_GEOMETRY='geojson'
npm.cmd run build
Remove-Item Env:VITE_MAP_GEOMETRY
```

Cloudflare Pagesなどのビルド環境変数でも同じ指定を上書きできます。生成タイルと元データは両方保持します。
ブランチごと戻す場合は試作差分を保存してから`main`へ切り替えます。未保存の変更を破棄しないでください。

## 生成と互換性

`npm run data:build:base-map-tiles`で市区町村・都道府県を同じタイルに事前変換します。
MapLibre 5.24のGeoJSON変換と同じextent 8192 / buffer 2048 / tolerance 6 / maxZoom 18です。
地図の最大倍率10までを出力し、追加の簡略化はしません。更新時は元データの変更後に再生成します。
市区町村・都道府県・補正形状の3入力の内容と変換条件・エンコーダーバージョンからURLの版を決め、版付きタイルだけを長期キャッシュします。
入力ハッシュと版の計算ではCRLFをLFへ揃え、WindowsとLinuxのチェックアウト差で版が変わらないようにしています。
古い版の生成ディレクトリが残った場合、現在のmanifestが参照していないことを確認して整理してください。

市区町村コードは文字列のまま保持します。feature-stateにはsourceLayerを付け、
複数タイルに分割された市区町村にも同じ警報色を反映します。
青森市・西条市・別府市・岬町・上越市は、生成時にコードをキーとして補正GeoJSONの形状へ置き換えます。
修正済みの座標列・穴・島・MultiPolygonをそのまま入力し、属性と先頭ゼロを保ちます。
タイル版では補正版専用ソース・レイヤー・除外フィルター・先読みを使用せず、
警報のfeature-stateとクリックも通常市区町村ソースに統一します。
GeoJSON版への切り戻し時だけ、従来の補正版ソースと除外フィルターを使用します。
海外の海岸線、震度の区域・観測点、EEW、検索用形状は変更しません。
海のみの区画はmanifestで判別し、ネットワークへ要求しません。

生成済みファイルは1,428枚・約14.1MB（圧縮前）。Cloudflare Workers・D1・新しいサーバーは追加しません。
静的ファイルの要求数は増えるため、転送量とキャッシュの実運用は公開前に確認します。

本番CDN・iPhone・低速回線の測定ではありません。
公開前に実際の警報更新、早期注意情報、補正市区町村、倍率変更中のクリック、
地震タブと他タブの切り替え、通信断からの復帰を実機でも確認します。

## 2026-11-13 初期表示の修正

基図のfill・line・クリック用レイヤーは初期スタイルから表示状態とし、DOMの読み込み画面で露出を制御します。
`load`で初めて可視化する方式を廃止し、MapLibreが最初の表示範囲のタイルを取得できるようにしました。
読み込み完了は必要な基図ソースの`isSourceLoaded()`とレイヤーの有効性を、描画後の`render`イベントで確認します。
ベクトル版の必須ソースは市区町村ソース1つ（都道府県も同じタイル）、GeoJSON版は市区町村・補正版・都道府県の3つです。
地図全体の`idle`や固定フレーム数には依存しません。

MapLibreはエラーになったタイルも「完了」とみなすため、必須ソースのエラーを別途監視して失敗として扱います。
既存の8秒の起動期限も成功とはみなさず、エラー表示と10秒後の自動再読み込み・手動再読み込みへ接続します。
任意の海外地図・雨雲などのソースは完了条件に含めません。成功・失敗とも監視イベントとタイマーを解放します。

### ブラウザー検証の再現方法

```powershell
node scripts/serve-map-loading-check.mjs
# http://localhost:5188/Tests/browser/initial-map-loading.html?case=slow
```

実際の`createWeatherMap`とMapLibreを使用するローカル専用画面です。本番ビルドには含まれません。
`case=slow`は通常タイルを2.5秒遅延、`fail`はHTTP 503、`timeout`は12秒遅延、
`optional`は別のGeoJSONソースを20秒遅延させます。指定なしは通常条件です。
画面の`readySnapshot`で完了時の未処理タイル数・任意ソースの状態・実描画図形数を確認できます。
5市町の架空警報・早期注意色、解除、青森市のズームとクリック、テーマ・タブ切替も操作できます。
GeoJSON版は`MAP_QA_GEOMETRY=geojson`を指定して同じサーバーを起動します。
