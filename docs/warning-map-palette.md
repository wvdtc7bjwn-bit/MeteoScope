# 地図の警報色

2026-11-20に利用者から提供された参考画像（1179×1894px）から、ヘッダーを除く y=330..1893 の地図部分を解析。文字・境界・背景を避けるため、HSVで彩度>0.23・明度0.2..0.8の画素を色相ごとに分類し、RGB各成分の中央値を採用した。

| 種類 | 抽出RGB | 抽出色 | 抽出画素数 |
| --- | --- | --- | --- |
| 注意報 | 166,153,78 | `#a6994e` | 461097 |
| 警報 | 113,43,39 | `#712b27` | 172945 |
| 危険警報 | 84,72,107 | `#54486b` | 30439 |
| 特別警報 | 危険警報と同じ | 紫＋黒斜線 | 利用者の指定 |

その後、実画面を見た利用者の明るさ・鮮やかさの指定に合わせ、RGBの各成分を1.2倍（四捨五入）した後、HSVの彩度を1.2倍・明度を1.1倍に調整した。最終配色は注意報 `#dbc750`、警報 `#962720`、危険警報・特別警報の下地 `#69558d`。

画像には地形陰影・圧縮・半透明の影響があるため単色の正解値はなく、抽出値は表示された塗りの代表色。既存の地図塗りの透過率（ズームにより0.92〜0.96）は維持するため、背景・地形・テーマにより最終画素には微小な差がある。

`src/warningMapColors.js` を地図・凡例の共有定義とする。特別警報だけは透明地の黒斜線パターンを上から重ねる。注意報・警報・危険警報には斜線を出さない。湖上も陸地と同じ市区町村feature-stateを使うので、発表・変更・解除が一致する。

これは地図の配色変更であり、発表情報の判定、早期注意情報、キキクル、河川のレベル色、津波や地震の色を変更するものではない。
