主な情報出典
気象庁ホームページおよび気象データ高度利用ポータルサイト

地震情報
通常時の地震情報はP2P地震情報 JSON API v2でリアルタイム受信し、気象庁防災情報XMLを正式値・詳細情報・履歴の取得に併用します。Wolfxは緊急地震速報の取得だけに使用します。

雷情報
気象庁の雷ナウキャストと雷監視システム（LIDEN）の公開データをもとに、MeteoScopeが雷活動度を地図へ重ね、対地放電（落雷）を「×」、雲放電を「○」に加工して表示しています。独自の雷予報・警報ではありません。LIDENには誤標定、位置誤差、未検知が生じる場合があります。

地震・津波・火山情報の取得経路
Web版が気象庁防災情報XMLの地震火山フィードと各電文を取得し、推計震度分布は気象庁の公開分布図を対応する地震へ照合します。火山情報では気象庁の全国現況・火山一覧も照合して、MeteoScopeが正規化して表示しています。

緊急地震速報
気象庁の緊急地震速報をWolfx Open API経由で取得します。P波・S波の円は震源時刻・深さとJMA2001走時表から算出した概算表示で、気象庁が発表した到達予想ではありません。仮定震源要素やPLUM法など、震源情報が不確かな場合は円を表示しません。通信遅延や欠測があり得るため、重要な判断では気象庁などの公式情報を確認してください。

区域の形状
市区町村境界、地震区域、都道府県境界は、気象庁の予報区等GISデータをGeoJSONへ変換し、区域コード・名称・表示用属性を付加して利用しています。原データには国土地理院の測量成果が使用されています。

震度観測点
気象庁の震度観測点で公開されている、気象庁・地方公共団体・防災科研の観測点名称、表示用座標、所属区分を加工して利用しています。

背景地図
国土地理院の地理院タイル（標準地図）を背景として利用し、その上に気象・防災情報を重ねています。

活断層
通常表示には防災科学技術研究所のJ-SHIS主要活断層帯（2022年版・最大ケース）を利用しています。管理者が個別に許可したアカウントでは、産業技術総合研究所 地質調査総合センター「活断層データベース」の活動セグメントをMeteoScopeがGeoJSONへ変換・表示用に加工したデータを表示します。アカウントがない場合や許可されていない場合はJ-SHISを表示します。

プレート境界
U.S. Geological Survey（USGS）のTectonic Plate Boundaries（境界モデル: Bird, 2003）から日本周辺を抽出し、収束境界・横ずれ境界・その他をMeteoScopeが配色して地震タブへ重ねています。境界線は科学モデルに基づく概略位置で、個別地点の危険度や断層位置を示すものではありません。

プレート面・等深線
U.S. Geological Survey（USGS）のSlab2から日本周辺の沈み込むプレート上面の深さを20km間隔で抽出し、浅い側を赤、深い側を青の連続色で地震タブへ重ねています。立体表示の面は、USGSの収束境界を0km側の端とし、隣接する等深線間をMeteoScopeが補間した概略表現です。距離が離れた箇所やデータの裏付けがない隙間には面を張りません。CC0の静的データを使用し、Web版で3D表示します。モデル値・補間表示であり、地下の境界位置や危険度を地点単位で確定するものではありません。

指定河川の形状
ESRIジャパン「指定河川洪水予報河川および洪水予報河川」を利用しています。原典は気象業務支援センターが公開する流路データと河川名対応表、気象庁の個別コード表です。MeteoScopeが気象庁XMLの発表情報と照合し、地図上の配色と表示を加工しています。

加工について
気象庁の公開データをもとに、MeteoScopeが地図への重ね合わせ、区域との照合、グラフ・ランキング化、表示用の配色・表記変換、通知状態の比較を行っています。表示内容は気象庁が作成した画面そのものではありません。

警報・予報の扱い
本アプリは独自の気象予報・警報を発表するものではなく、気象庁が発表した情報を加工・可視化する非公式アプリです。通知の「発表・継続・切替・解除」は、気象庁発表データの変化をMeteoScopeが比較した表示です。

利用時の注意
重要な防災判断では、発表時刻を確認し、気象庁防災情報や自治体などの公式情報を併せて確認してください。データの停止、遅延、更新または仕様変更により、表示が最新でない場合があります。

利用条件
気象庁コンテンツは、原則として気象庁ホームページの利用規約および公共データ利用規約（第1.0版）に基づいて利用しています。

MeteoScopeは、公開データとオープンソースソフトウェア、ならびに情報を整備・提供する各機関の協力によって成り立っています。関係する皆さまに感謝します。

気象・防災データ
気象庁、国土地理院、防災科学技術研究所（J-SHIS）、U.S. Geological Survey（USGS）、ESRIジャパン株式会社の公開情報・データを利用しています。個別の出典・利用条件は「情報出典・加工」に記載しています。

地形表示
色別標高図・陰影起伏図は国土地理院の地理院タイルを利用しています。色別標高図の海域部は海上保安庁海洋情報部の資料を使用して作成されています。

技術基盤
